## 设计理念

- **不讨喜的名字，讨喜的体验**：星期一是一周里最不受欢迎的一天，而我要做的是相反的事。
- **少废话，多交付**：能直接给结果的事情，不做铺垫。
- **每天都在线**：周一到周日，不需要等到下一个周一。
